# おひまの習慣帳 🌷

ジム・TOEIC勉強・読書の「できた」を、毎日少しずつ残す日本語のWebアプリです。淡いグリーン・ラベンダー・ベージュを使い、iPhoneでも押しやすい画面にしました。アカウント登録は不要です。

## できること

- 3つの習慣の達成をワンタップで記録・取り消し
- 過去の日の記録と、日付をタップして移動できる週間カレンダー（月曜始まり）
- 選択日の達成率と週間達成率
- 習慣ごとの連続達成日数
- 日付ごとのメモ（最大2,000文字・入力するたび自動保存）
- 同じブラウザに記録を自動保存

週間達成率は、その週の月曜日から今日までの「達成数 ÷（日数 × 3）」です。過去の週は7日分で計算します。未来の日は記録・計算の対象外です。

連続達成日数は選択日から過去に向かって数えます。ただし今日が未達成の場合は昨日から数えます。今日の途中で連続記録が消えないようにするためです。日付は使っている端末の現地時間です。以前のバージョンの「勉強」の記録は「TOEIC勉強」に引き継ぎます。

## パソコンで動かす（初めての方向け）

必要なのは **Python 3** だけです。Node.jsやパッケージのインストール、ビルドは不要です。

1. [Python公式サイト](https://www.python.org/downloads/)からPython 3をインストールします。Windowsではインストール時に「Add Python to PATH」を選んでください。
2. このリポジトリをダウンロードして展開します。
3. ターミナル（WindowsではPowerShell）を開き、`cd` の後にフォルダの場所を入力して移動します。例：`cd Downloads/ohima-habit-tracker-main`。
4. 次のコマンドを実行します。

   ```sh
   python3 -m http.server 3000 --bind 0.0.0.0
   ```

   Windowsで`python3`が見つからない場合は次を使います。

   ```powershell
   py -m http.server 3000 --bind 0.0.0.0
   ```

5. パソコンのブラウザのアドレス欄に `http://localhost:3000` を入力します。
6. 終了するには、ターミナルで **Ctrl + C** を押します。

Node.jsがある場合は、同じフォルダで `npm start` でも起動できます（Python 3も必要です）。`index.html`を直接ダブルクリックするとJavaScriptの読み込みが制限されるため、上の手順で開いてください。

## iPhoneで使う

### 同じWi-Fiで試す

1. パソコンで上記のサーバーを起動したままにします。
2. パソコンとiPhoneを同じWi-Fiに接続します。
3. パソコンのWi-Fi設定で「IPアドレス」を確認します（例：`192.168.1.10`）。
4. iPhoneのSafariのアドレス欄に `http://192.168.1.10:3000` のように、パソコンのIPアドレスと`:3000`を入力します。

開けない場合は、パソコンのファイアウォールでPythonのローカルネットワークへの接続を許可し、同じWi-Fiか確認してください。パソコンの電源やサーバーを止めるとページは開けなくなります。iPhoneで`localhost`と入力してもパソコンには接続できません。

### 日常的に使う

このフォルダをGitHub Pagesなどの静的サイト配信サービスでHTTPS公開すると、パソコンを起動しなくてもアクセスできます。GitHub Pagesの場合は、GitHubのリポジトリ画面の **Settings → Pages → Deploy from a branch** で、アプリを保存したブランチと`/ (root)`を選択して保存します。先にアプリのファイルをそのブランチへコミット・プッシュしてください。

Safariで公開URLを開き、共有メニューから **ホーム画面に追加** を選べば、ホーム画面から開けます。このアプリにオフライン起動の保証はありません。

## 使い方と保存について

「達成を記録する」を押すとチェックが付き、もう一度押すと取り消せます。日付欄・矢印・週間カレンダーで日付を切り替え、「今日」で戻れます。メモは日付ごとに保存します。

データは **localStorage（ブラウザ内の保存場所）** にだけ残ります。サーバーへ送信しません。端末・ブラウザ・URLの組み合わせが変わると記録は共有されません。ローカルURLから公開URLへ変更した場合も引き継がれません。プライベートブラウズ、サイトデータの削除、端末の変更によって記録が失われる場合があります。バックアップ・端末間同期機能はありません。

保存に失敗した場合は画面に案内を表示します。その場合は画面を閉じる前にメモを別の場所に控え、ブラウザの保存設定や空き容量を確認してください。外部フォントを取得できなくても端末の標準フォントで動作します。

## 開発・テスト

Node.js 18以上で、次を実行します。

```sh
npm test
```

日付、週の境界、達成数、連続達成日数、メモの保持、週間達成率を検証します。

- `index.html`：画面
- `style.css`：見た目とiPhone向けレイアウト
- `app.js`：操作とブラウザ保存
- `habits.mjs`：日付・達成率・連続日数の計算
- `habits.test.mjs`：計算と保存形式のテスト
